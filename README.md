# 고운 마케팅 스튜디오

가게·스토어·쇼핑몰 홍보 대행을 AI로 처리하는 내부 툴 (고운기획)

| 탭 | 하는 일 |
|---|---|
| 🔍 정밀 진단 | 업체 스토어 상품 페이지에서 '고운 진단' 북마크 버튼 클릭 → 손님이 보는 화면 그대로 가져와 AI가 읽음 → 100점 진단서(상품명·노출·가격·구매전환·상세페이지·리뷰 불만·법규) + 할 일 TOP3 → 고객용 링크(/d). 검색 결과 화면도 가져오면 순위·경쟁 가격 비교 추가. 검색광고 키가 있으면 **📊 한눈에 보기 · 🔎 관련 키워드 월 검색량(PC/모바일, 상품명 포함 여부) · 🔬 데이터 과학 분석**(멱법칙·틈새 지수·검색 파동·가격 백분위·타협 효과·순위 속도) 추가 |
| ✍️ 홍보 카피 | 인스타·블로그·플레이스·당근·카톡채널·파워링크·현수막 문구를 채널 규칙에 맞춰 한 번에 생성 |
| 📊 전략 리포트 | 채널 우선순위, 4주 캘린더, 예산 배분, KPI → 고객 전달용 HTML 저장 |
| 🖼️ 카드뉴스 | 원고 생성 + 1080×1350 PNG 자동 디자인, 텍스트 수정, ZIP 다운로드 |
| 🎬 숏폼 자동편집 | 무음 자동 컷 → 9:16 변환 → 자막(받아쓰기/AI)·상단 타이틀·CTA·BGM → MP4 |
| 📋 고객 리포트 | 순위·작업 내역 자동 수집 + 핵심 숫자 입력 → AI 요약 → 고객용 공유 링크(/r) · HTML |

고객사 정보는 프로필로 저장해두고 골라 쓰면 모든 탭에 적용됩니다 (브라우저에 저장).

## 실행

```bash
npm install
cp .env.example .env.local   # 키 입력
npm run dev                  # http://localhost:3000
```

## 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ | 카피·전략·카드뉴스·AI 자막 |
| `OPENAI_API_KEY` | 선택 | 숏폼 '말소리 받아쓰기' 자막 (없으면 AI 자막 모드만 사용) |
| `NCP_HUB_CLIENT_ID` / `NCP_HUB_CLIENT_SECRET` | 선택 | 진단의 시즌 분석. 네이버클라우드 → NAVER API HUB → Search Trend |
| `NAVER_AD_API_KEY` / `NAVER_AD_SECRET` / `NAVER_AD_CUSTOMER_ID` | 권장 | 진단의 키워드 검색량·경쟁 정도 + **📣 광고 제안**(추천 키워드 그룹·예상 입찰가·월 예상 성과·제외 키워드). 네이버 검색광고 → 도구 → API 사용 관리 |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | 권장 | 고객용 **짧은 링크**. Vercel → Storage → Upstash for Redis(무료) 연결 시 자동 입력. 없으면 긴 링크로 대체 |
| `APP_PASSWORD` | 권장 | 배포 시 남이 API 크레딧 못 쓰게 막는 접속 비밀번호 (앱 오른쪽 위 🔑에 입력) |
| `ANTHROPIC_MODEL` | 선택 | 기본 `claude-sonnet-5-5` |

## 여러 명이 같이 쓸 때 (모임 공유)

- 스토어 정보·순위 기록은 **각자 브라우저에 저장** → 서로 안 보임
- API 비용은 배포한 사람 키로 나감. 1인당 시간당 제한 있음 (AI 40회, 받아쓰기 20회)
  - 바꾸려면 환경변수 `LIMIT_AI_PER_HOUR`, `LIMIT_STT_PER_HOUR`
- `APP_PASSWORD`를 걸고 모임에만 공유 권장

## Vercel 배포

1. `goun-0728` 조직에 새 저장소로 푸시 — **ZIP을 푼 파일들이 저장소 맨 위에 오게** (package.json이 바로 보여야 함)
2. Vercel → New Project → 저장소 선택 (Next.js 자동 인식)
3. Settings → Environment Variables에 위 키 입력 → Deploy

## 숏폼 편집 참고

- 영상은 서버에 올라가지 않고 **브라우저에서 처리** → 서버 비용·용량 제한 없음
- 실시간 합성이라 **영상 길이만큼 시간이 걸림**, 그동안 탭을 앞에 띄워둘 것
- **크롬 최신 버전 권장** (MP4로 저장됨. 다른 브라우저는 WebM)
- 받아쓰기는 약 2분까지 (Vercel 요청 크기 4.5MB 제한)
- 아이폰 HEVC(.mov) 영상은 크롬에서 안 열릴 수 있음 → 카메라 설정 '높은 호환성' 또는 변환 후 사용

## 정밀 진단 참고

- 네이버 쇼핑 검색 API는 2026-07-31 종료 → 서버가 네이버에 접속하지 않고, **사용자가 보고 있는 화면**을 북마크 버튼으로 가져와 분석
- PC 크롬 기준. 버튼을 누를 때마다 스튜디오 새 탭이 열림 (이전 탭은 닫아도 됨, 가져온 내용은 공유됨)
- 상세페이지는 '상세정보 펼쳐보기' 후 아래까지 내린 다음 버튼을 눌러야 이미지까지 분석
- 한 번에 한 업체씩, 사람이 보는 속도로만 사용 (대량 자동 수집 금지)

## 결과 유지 · 보고서

- 각 탭의 생성 결과는 **다시 생성 버튼을 누르기 전까지** 탭을 옮기거나 새로고침해도 유지 (스토어별로 따로 저장, `gms_out_*`)
- 진단서·고객 리포트·전략·홍보 문구·카드뉴스: **📄 보고서 PDF**(인쇄 창 → 'PDF로 저장') / **HTML 저장**

## 데이터 보존 (업데이트 규칙)

- 스토어·리포트·진단 기록은 각 사용자 브라우저(localStorage)에 저장 → **재배포해도 유지**됨
- 주소(`*.vercel.app`)가 바뀌면 새 주소에서는 안 보임 → 도메인을 바꿀 땐 먼저 '백업 파일 받기' 후 새 주소에서 '백업 불러오기'
- 코드 수정 시 `lib/storage.js`의 저장 키 이름을 절대 바꾸지 않기. 구조 변경은 새 키 추가 + 옛 키에서 옮겨오기
- 스토어 목록은 예비 사본(`gms_profiles_shadow`)이 있어, 본 저장이 비거나 깨지면 자동 복구
